# 完了コメントの書式

作業が終わったら PR にコメントする。

```markdown
実装が完了した。

- 実装: <一行で何をしたか>
- レビュー: `pr-review` を <n> 周実施。<blocker n件 / should n件> を反映済み
- 残っている判断: <あれば。無ければ「なし」>

マージの可否は判断してほしい。
```

## 書くときの判断

**このコメントは通知として届く。** PR 本文が「何を変えたか」の正本で、こちらは「終わった・見てほしい」の合図。本文の内容をここへ複製しない。

**レビュー周回数を書くのは、どれだけ詰めたかが分かるようにするため。** 1 周で指摘ゼロだったのか、3 周で収束したのかで、読み手の警戒度は変わってよい。

**マージは人が決める。** コメントで催促しない。判断材料を渡すだけにする。
