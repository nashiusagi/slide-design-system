# DR-0012: 本文の最小フォントサイズは 18px とする

- **状態**: 承認済み
- **日付**: 2026-09-06
- **関連**: [DR-0006](./0006-online-sharing-first.md), [DR-0011](./0011-lint-and-measure.md)
- **正本**: `design/rules.json`（`min-font-size` の閾値）, `design/tokens.json`（`type.*`）

## 文脈

`min-font-size` は measure 系検査の一つ（[DR-0011](./0011-lint-and-measure.md)）であり、閾値を決めないと実装できない。適切な値は視認距離に依存する。

## 決定

下限を 18px とする。値は `design/rules.json` を正本とし、このDRには複製しない。

## 理由

- オンライン共有優先（[DR-0006](./0006-online-sharing-first.md)）のため、遠距離視認を前提とした 24〜28px は過剰
- 一方で 16px（Web の本文標準）はスライドとしては小さい。画面共有では相手の表示倍率が下がることがあり、余裕を持たせる必要がある
- 18px は情報密度と可読性の折り合いが取れる

## 検討した他の選択肢

### 24px 以上

カンファレンス登壇を想定した値。

**却下理由**: 用途と合わず、1 枚に載せられる情報が過度に減る。

### 16px

**却下理由**: 画面共有時の縮小に耐えない。

## 帰結

- `type` トークンのスケールはこの下限を割らないように設計する
- 閾値の変更は `design/rules.json` の編集で行い、このDRは「なぜその水準か」の根拠として残る
