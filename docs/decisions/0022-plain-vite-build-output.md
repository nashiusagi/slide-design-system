# DR-0022: 最終出力は `vite build` の素の成果物とする

- **状態**: 承認済み
- **日付**: 2026-09-06
- **関連**: [DR-0002](./0002-source-format-jsx-react.md), [DR-0011](./0011-lint-and-measure.md)

## 文脈

JSX / React で書き、静的出力へビルドすると決めた（[DR-0002](./0002-source-format-jsx-react.md)）。`vite build` の素の出力は `index.html` + `assets/main-xxx.js` + `assets/main-xxx.css` の複数ファイル構成になる。単一 HTML へインライン化する選択肢もある。

## 決定

`vite build` の素の成果物（`index.html` + `assets/`）をそのまま最終出力とする。単一ファイル化は行わない。

## 理由

- 構成がシンプルで、ビルド手順に追加の層が要らない
- 画像を base64 化する必要がなく、サイズが膨らまない
- 単一ファイル化が必要になった時点で、プラグイン 1 つで足せる

## 検討した他の選択肢

### 単一 HTML へインライン化

CSS / JS / 画像をすべて `index.html` へ埋め込む。メールで送る、オフラインで開くといった配布のしやすさが最大。

**却下理由**: 現時点で単一ファイルで渡す要求がない。画像の base64 化によるサイズ膨張と、ビルド手順の追加が対価として見合わない。

### 静的ビルド + PDF 書き出し

**却下理由**: PDF は Phase 1 のスコープ外（[DR-0004](./0004-phase-1-runtime-scope.md)）。

## 帰結

- measure 検査（[DR-0011](./0011-lint-and-measure.md)）はこのビルド出力に対して実行する。本番と完全に同一の物を検査することになる
