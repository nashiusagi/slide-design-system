# DR-0020: 実験スクリプトは AI を起動しない

- **状態**: 承認済み
- **日付**: 2026-09-06
- **関連**: [DR-0019](./0019-claude-only-runner.md), [DR-0014](./0014-baseline-comparison.md)

## 文脈

Atlas の `pnpm experiment:run` はエージェント CLI を起動して生成まで行っていた。しかしこのプロジェクトでは生成をサブエージェントで手動起動すると決めた（[DR-0019](./0019-claude-only-runner.md)）。スクリプトの責務を再定義する必要がある。

## 決定

スクリプトの責務を以下に限定し、AI の起動は含めない。

1. 隔離ワークスペースの用意
2. 生成結果の取り込みと Run 保存
3. 検査（lint / typecheck / test / build / measure）
4. 採点（ルール別の pass / fail / review）
5. Baseline / Harness / Harness-corrected の比較表出力

## 理由

- 生成は 1 回だけ、採点は何度でも無料で再実行できる。トークン消費が完全に制御できる
- ルールを追加したとき、保存済み Run へ遡って効き目を確認できる。AI の再実行が不要
- スクリプトが AI の実行環境に依存しなくなり、テストが書きやすい

## 検討した他の選択肢

### Atlas と同じく生成まで自動化する

一括実行でき、再現性が高い。

**却下理由**: [DR-0019](./0019-claude-only-runner.md) の通り、トークン消費の可視性と運用要望に合わない。

## 帰結

- Run の保存形式（JSON Schema）が重要になる。生成結果を後から取り込める形にしておく必要がある
- 生成の手順は人間向けドキュメントとして明記する。公平性は手順の遵守で担保される
