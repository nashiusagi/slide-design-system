# DR-0008: アクセントの赤紫はパープル寄りにする

- **状態**: 承認済み
- **日付**: 2026-09-06
- **関連**: [DR-0007](./0007-north-star.md)
- **正本**: `design/tokens.json`（`color.accent` / `color.accentSoft`）

## 文脈

北極星（[DR-0007](./0007-north-star.md)）でアクセントを赤紫の一色と定めた。赤紫にはマゼンタ寄りとパープル寄りの幅があり、どちらを取るかで印象と、`danger`（赤）との識別性が変わる。

## 決定

パープル寄りを採る。具体値は `design/tokens.json` を正本とし、この DR には複製しない。

## 理由

- `danger` の赤と色相が十分離れ、状態色との混同を避けられる
- マゼンタ寄りより彩度の主張が穏やかで、「静かな紙面」という北極星に沿う
- 白背景に対して十分なコントラストを取りやすい

## 検討した他の選択肢

### マゼンタ寄り

より鮮烈で目を引く。

**却下理由**: 赤との色相距離が縮まり、`danger` との識別性が落ちる。また主張が強く、北極星の「静かさ」と競合する。

## 帰結

- `design/tokens.json` の作成時（Issue #4）に、oklch で具体値を決め、全色ペアのコントラストを実測してコメントとして記録する
- 満たすべきコントラストの基準は `design/rules.json` の `contrast` を正本とする
- `accent` と `danger` の色相差は、oklch の色相角の差として実測し、コントラスト実測値と並べて `design/tokens.json` のコメントへ記録する。合否に使う下限値は `design/rules.json` に置く
