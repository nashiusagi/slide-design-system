# DR-0007: 北極星は「白い紙面と黒い文字。強調は赤紫の一色だけ」

- **状態**: 承認済み
- **日付**: 2026-09-06
- **関連**: [DR-0008](./0008-accent-hue-purple.md), [DR-0005](./0005-single-theme-personal.md)
- **正本**: `DESIGN.md`（記述）, `design/tokens.json`（値）

## 文脈

Atlas は `DESIGN.md` の冒頭で北極星を「整った業務台帳」と一言で定め、そこから全トークンとルールを導出していた。デザインシステムには、個別判断の拠り所となる一行が要る。それが無いと、AI も人間も判断のたびに一貫性を失う。

## 決定

**「白い紙面と黒い文字。強調は赤紫の一色だけ」** を北極星とする。装飾で語らず、余白と文字の階層だけで構造を示す。色は意味のある場所にしか現れない。

具体的な値は `design/tokens.json` を正本とし、このDRには複製しない。

## 理由

- 内容（文字・コード・図）を主役にできる。オンライン共有優先（[DR-0006](./0006-online-sharing-first.md)）で「後から読む資料」として機能させるのに適する
- アクセントを 1 色に絞ることで、`danger` / `warning` / `success` を意味色として温存できる。強調と警告が色で衝突しない
- 単一テーマ（[DR-0005](./0005-single-theme-personal.md)）でのコントラスト検証が単純になる
- 図やスクリーンショット（多くは白背景）を貼ったときに浮かない

## 検討した他の選択肢

### ダーク基調

黒背景でコードが映え、長時間の閲覧で目に優しい。

**却下理由**: PDF 化・印刷で取り回しが悪く、白背景の図やスクリーンショットを貼ると調和しない。

### 大胆な余白と大文字（1 枚 1 メッセージ）

**却下理由**: 登壇には強いが、枚数が膨らみ、後から読む人に情報が残らない。オンライン共有優先（[DR-0006](./0006-online-sharing-first.md)）と衝突する。

## 帰結

- `DESIGN.md` の Do / Don't と Global Constraints はこの一行から導出する
- 「色だけで意味を伝えない」「アクセントは 1 領域に 1 箇所まで」といったルールが従属して決まる
