## should

### `writing/contradictory-instruction` — 母数に除外条件を足したのに、置き換えた範囲の宣言は「母数はそのまま有効」と書く

- **場所**: `docs/decisions/0059-self-check-done-covers-ready-diff.md`:39（決定3）, :77（帰結1行目）, :80 ／ `docs/decisions/0057-self-check-before-ready.md`:3（状態欄）, :60（決定7 に足した段落）, :93（帰結）
- **指摘した観点**: 設計契約との整合 / 検査ルールの実効性 / 決定記録（DR）との整合 / フェーズスコープ / 日本語ドキュメント
- **累計**: 14回目
- **何が起きているか**: DR-0057 決定7 の母数は「この段を通した PR だけ」。DR-0059 決定3 はそこへ「1周目に観点が欠けた PR を除く」を足し、帰結の末尾もそれを述べる。一方、DR-0057 の状態欄は置き換えた範囲を「計上回数と基準値を数える範囲」に限り、DR-0057 決定7 に足した段落と DR-0059 帰結1行目は「母数（の取り方）は、そのまま有効」と書く。
- **なぜ問題か**: `docs/decisions/README.md` の一部置き換えの運用は、状態欄から有効・無効を読めることを求める。DR-0057 だけを読むと、母数の除外が見えない。#77 は DR-0057 を拠り所に `self-check.md` / `review-log-format.md` を揃えるので、除外が実装から落ちうる。Issue #76 のゴール「DR-0057 の状態欄が、置き換えられた範囲に合わせて更新されている」も満たしていない。
- **失敗シナリオ**: 5本のうち1本で1周目に観点が1つ落ちる。DR-0057 に従ってその PR を母数に入れると、分子が小さく出て「段が効いた」と記録される——DR-0059 決定3 が塞いだはずの穴。
- **提案**: 置き換えた範囲に「母数から除く条件」を加え、「そのまま有効」の列挙から「母数」を外して「`済` の PR に限ること」へ狭める。DR-0057 の状態欄・決定7 の段落・帰結、DR-0059 の帰結1行目の4箇所を揃える。

### `writing/ambiguous-criterion` — 1周目の観点が全滅して周に数えられた PR が、除外条件「一部の観点」に当たらない

- **場所**: `docs/decisions/0059-self-check-done-covers-ready-diff.md`:37, :39
- **指摘した観点**: 検査ルールの実効性 / 日本語ドキュメント
- **累計**: 15回目
- **何が起きているか**: `issue-workflow` 手順5 は「3度目も1件も返らなければ、その回を1周として数える」。この回が1周目になると、全観点が結果を返していない。決定3 の除外は「一部の観点が結果を返さなかった PR」とだけ書き、全観点が返らなかった場合を含むかが読めない。
- **なぜ問題か**: 含まないと読めば、指摘を数えられなかった周が「対象8カテゴリ0回」として分子に入り、5本平均を最も強く押し下げる。
- **失敗シナリオ**: 外部の制約で1周目のレビュアーが3度とも全滅した PR が、計上0回として5本に入り、段が何もしていなくても「効いた」と出る。
- **提案**: 「結果を返さなかった観点が1つでもある（全観点が返らなかった場合を含む）」と書く。

### `phase/scope-rationale-contradicts-issue-text` — #77 へ渡した作業のうち2つが #77 の本文に無い

- **場所**: `docs/decisions/0059-self-check-done-covers-ready-diff.md`:79（帰結3項目目）／PR 本文「スコープ外」／Issue #77「やること」
- **指摘した観点**: フェーズスコープ
- **累計**: 2回目
- **何が起きているか**: DR-0059 の帰結と PR 本文は「1周目をレビュー記録から切り出す手順」と「基準値の数え直し（決定4）」を #77 が受け持つとする。#77 の「やること」「ゴール」にはどちらも無い。
- **なぜ問題か**: #77 の着手者はゴールだけを見て閉じられる。DR-0059 は「揃うまで基準値を比較に使わない」と決めているので、基準値の数え直しが漏れると DR-0057 決定7 の測定がいつまでも実行できない。
- **失敗シナリオ**: #77 が3ファイルを揃えて閉じ、基準値は全周の値のまま残る。5本たまった時点で、全周の基準値と1周目の分子を比べてしまう。
- **提案**: #77 にこの2つを追記し、PR 本文から追跡できるようにする。

### `writing/ungrammatical-sentence` — DR-0057 の帰結で句点が抜け、二つの文がつながっている

### `inspection/exit-decision-unverifiable` — 「1周目が見るのは Ready 化時点の差分」が、手順でも記録でも担保されていない

- **場所**: `docs/decisions/0059-self-check-done-covers-ready-diff.md`:35
- **指摘した観点**: 検査ルールの実効性
- **累計**: 2回目
- **何が起きているか**: 決定3 は1周目の範囲と `済` の範囲が「ちょうど重なる」と断定する。しかし Ready 化から1周目の呼び出しまでにコミットを足すことは禁じられておらず、レビュー記録は1周目に見たコミットを残さない。

- **提案**: 「重なる」を条件付きの表現に弱めるか、#77 の切り出し手順に、1周目の呼び出し時点のコミットと Ready 化時点の head を比べる確認を含める。
