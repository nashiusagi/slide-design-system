- **何が起きているか**: 実装フェーズの指示が、PR 本文への記載を DR の代替として明示的に認めている。二つの記録先が「か」で並び、どちらを選ぶかの基準も無い。
- **なぜ問題か**: `pr-review/agents/decisions.md` は「PR の説明に判断の理由が書かれている場合、それは DR に昇格すべき候補として扱う。PR の説明はマージ後に読まれないが、DR は残るからだ」と述べ、PR 本文への記載を到達点ではなく**指摘対象**としている。既知カテゴリ `decisions/undocumented-decision` の定義そのものが、この行が許容する状態を指す。新しい Skill が、同じリポジトリの `pr-review` が指摘する行為を正規の選択肢として指示している。このスキルは今後すべての Issue 実装の入口になるため、影響は1回の PR に留まらない。
